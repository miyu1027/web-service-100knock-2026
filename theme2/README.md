# 25. テーブルでデータを表形式で表示


| タグ       | 役割              |
|:-----------|-----------------:|
| <table>    | 表全体を定義する  |
| <thead>    | 表の見出し部分    |
| <tbody>    | 表のデータ部分    |
| <tr>       | 表の1行を定義する |
| <th>       | 見出し用のセル    |
| <td>       | データ用のセル    |
